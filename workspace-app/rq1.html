RQ1 analysis

RQ1: Evaluate the appropriateness of data analysis strategies for use with qualitative research methodologies.

Scholarly statement

This amalgamated dataset exists so that analysis decisions can be inspected against the same objects the interviews will produce: citations, constructs, questions, excerpts, codes, and parking-lot exceptions. The member’s design is generic qualitative inquiry, not phenomenology, grounded theory, ethnography, or a survey-regression study. Generic qualitative work studies how participants interpret processes, conditions, and actions in a bounded setting (Caelli et al., 2003; Kahlke, 2014; Tisdell et al., 2025). The corresponding instrument is a semi-structured, critical-incident interview in which the researcher is the instrument. An appropriate analysis strategy must therefore stay close to participant meaning, remain open to patterned themes, and still allow a declared theoretical lens to sensitize—not dictate—coding.

Reflexive thematic analysis is the most appropriate general-purpose strategy for this dataset. It can be used inductively enough to honor generic qualitative aims, while still permitting theory-informed theme development once constructs such as stakeholder salience, decision-rights clarity, and leadership self-discipline have been named (Braun & Clarke’s reflexive tradition as already recommended in the source tool memo). Theory-informed thematic analysis, as classified on the dissertation spine, is appropriate as a companion—not a replacement—because the spine already treats power, legitimacy, and urgency as sensitizing concepts. Delve is the CAQDAS product the member uses for coding, retrieval, memoing, and audit. CAQDAS names the software category; it is not the tool of record. Delve does not supply a methodology. Course readings that mention NVivo remain in the archive as category examples, not as the working application.

Strategies that are not appropriate for extraction from these interviews include simple linear regression, a priori power analysis as a substitute for information power, instrument scoring keys, and any codebook that treats leadership-trust or knowledge-sharing survey items as if they were the member’s variables. Those procedures belong to the archived comparative sheet. Using them on interview transcripts would misrepresent both the methodology and the participants. Likewise, a rigid grounded-theory mandate would over-claim theoretical generation, and a phenomenological reduction would over-claim lived-essence findings that the generic qualitative questions are not built to produce.

Question–theory alignment is an ethical control, not a formatting preference. A review question must test the same construct as its parent question. When a prompt does not map to a defined construct, any extract taken from the answer is researcher invention: the dataset cannot show why that utterance was eligible for coding. Alignment of the full set of tables—references, theory chart, leadership themes, interview protocol, parking lot, and analysis templates—creates a single audit trail: citation to construct to question to excerpt to code to theme to parked exception. That trail is what the aligned dataset does for later analysis. It does not analyze the interviews in advance. It makes later analysis accountable.

Trustworthiness follows the same trail. Credibility is supported by member-meaning checks (see IQ-08), dependability by an audit of IDs and memos, confirmability by the ability to return from a theme to an excerpt and a question, and transferability by transparent boundary conditions already stated on the spine (U.S. SMEs, ITDRPaaS recoverability assurance). Progressive focusing is permitted; undocumented drift from the protocol is not.
