README

This workspace amalgamates the BMGT 8044 reading-list workbook and the Week 7 leadership-theories alignment workbook without dropping source fields. The researcher uses it to keep references, constructs, interview questions, and analysis notes on one auditable trail.

How to move. The sticky table of contents above reaches every tab. The Dashboard (second page) is the only search surface. A parking-lot intake strip sits on every page and writes a local PL-L### item that the Parking lot tab displays beside the source rows.

What this amalgamated dataset is for

The member’s study is a generic qualitative inquiry that uses semi-structured, critical-incident interviews. Stakeholder theory and stakeholder-salience theory (power, legitimacy, urgency) supply the operational lens. Leadership-theory rows from Week 7 sit beside that spine so interview prompts can be checked against both governance constructs and leadership standards. Once those tables are aligned, an extract can be traced from citation to construct to question to excerpt to code. That trail is the ethical control on analysis.

Live design versus archive

  • Live. Reading-list citations, citation inserts, theory/spine tables, leadership themes, qualitative methods, Delve as the CAQDAS tool in use, reflexive thematic analysis, interview protocol, RQ1 statement, and analysis templates.
  • ARCHIVE_COMPARATIVE. The classmate Qualtrics / regression plan on leadership trust and knowledge sharing, plus quantitative methods notes. Those rows remain searchable and are labeled so they do not become the interview protocol.
  • Lineage. The formatted duplicate of the leadership workbook is retained under Source archive. The cleaner nine-row theme table is the canonical leadership tab.

Search rule

Typing on the Dashboard filters immediately. The last three distinct searches are stored only when the member presses Enter, clicks Search, or changes a facet. Clear filters does not erase that history. Refresh keeps the last three chips. Other tabs link back to the Dashboard with an optional ?q= prefill; they do not host a second search box.
