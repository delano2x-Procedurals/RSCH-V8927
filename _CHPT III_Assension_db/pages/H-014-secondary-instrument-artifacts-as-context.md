# CH3-H-014 · Secondary instrument: artifacts as context

**Chapter header:** [Secondary instrument: artifacts as context](../../docs/chapter-iii-methodology.md#secondary-instrument-artifacts-as-context)
**Level:** H3 · **Parent:** `CH3-H-011` · **Tester status:** Strong

## Purpose

Review objects the manager names in the incident via Path A (redacted share), B (verbal reconstruction), or C (none named).

## How to keep the spine intact

**Do.** File Path A as P##_ART##. Recode empty Path A after 14 days as Path B. Path C is a recoverability-assurance boundary.

**Do not.** Do not score artifacts against NIST/ISO/BCM. Do not invent contents the participant did not state. Refusal to share does not end the interview.
